# CoinFlow Support

Thank you for using CoinFlow. We're here to help.

If you have a question, encounter a problem, or would like to share feedback, please contact us using the email address below.

## Contact Us

Email: [eceakcay.dev@gmail.com](mailto:eceakcay.dev@gmail.com)

When reporting an issue, please include the following information when possible:

- A brief description of the issue
- The steps needed to reproduce it
- Your device model and operating system version
- Screenshots that help explain the problem

## About CoinFlow

CoinFlow is a cryptocurrency portfolio tracker that lets you follow market data, manage your favorite cryptocurrencies, record portfolio transactions, and monitor portfolio performance.

## Financial Disclaimer

CoinFlow does not provide financial or investment advice. Cryptocurrency prices and market data are provided for informational purposes only and may not be available in real time.
